STANDA COMMERCIAL — Rasin domèn nan -> Sit piblik la
════════════════════════════════════════════════════

SA CHANJMAN AN FÈ
  standacommercialsa.com            -> sit wèb piblik la
  standacommercialsa.com/dashboard  -> tablo de bò admin ou


KIJAN POU W METE YO SOU GITHUB
──────────────────────────────
1. Dezipe fichye a sou òdinatè w.
   W ap jwenn: app/ · components/ · lib/ · middleware.ts · next.config.mjs

2. Ale sou paj PRENSIPAL depo a (pa anndan yon dosye):
   github.com/standashippingsa-boop/claude-facture-standa

3. Anwo adwat: Add file -> Upload files

4. Trennen KAT bagay sa yo ANSANM nan fenèt la:
        dosye  app
        dosye  components
        dosye  lib
        fichye middleware.ts
        fichye next.config.mjs

   ⚠️ Trennen DOSYE yo, pa fichye ki anndan yo.
      Se konsa GitHub kenbe bon chemen an.

5. Desann anba, ekri yon mesaj (egzanp: "Rasin -> sit piblik")
   epi klike Commit changes.


POUKISA TOUT ANSANM FWA SA A
────────────────────────────
Nòmalman nou fè youn pa youn. Men uit fichye sa yo depann youn sou lòt:
si meni an pwente sou /dashboard anvan paj la egziste, w ap gen yon 404.
Yon sèl commit evite tout eta kase yo.


SA W AP TROUVE ANNDAN
─────────────────────
app/dashboard/page.tsx    NOUVO  — tablo de bò a (li te sou "/")

app/robots.tsx            chanje — Google pa gen dwa gade /dashboard
components/Sidebar.tsx    chanje — lyen Dashboard -> /dashboard
components/StaffLogin.tsx chanje — apre koneksyon -> /dashboard

middleware.ts             chanje — "/" -> "/accueil" anvan React monte
next.config.mjs           chanje — /dashboard pa kache nan navigatè


TÈS APRE VERCEL VÈT
───────────────────
1. standacommercialsa.com tou kout   -> sit piblik la
2. /admin-login, konekte             -> tablo de bò a
3. Meni gòch -> Dashboard            -> li mache
4. Konekte kòm kliyan                -> espas kliyan an

Si etap 2 mennen w sou sit piblik la, kanpe epi di m.
